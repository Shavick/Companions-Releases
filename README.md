# Companions - Releases

Downloads for **Companions**, a 7 Days to Die mod by Shavick that adds tamable companions to the game.

## Install

1. Download the latest `Companions-vX.Y.Z.zip` from [Releases](https://github.com/Shavick/Companions-Releases/releases).
2. Extract it so you have a `Companions` folder.
3. Put that folder in `%APPDATA%\7DaysToDie\Mods\` (create `Mods` if it doesn't exist). For a dedicated server, put it in the server's `Mods` folder. The server and every player need the same version.
4. Fully restart the game. Mods only load at startup.

Built for 7 Days to Die V3.4. EAC must be off.
